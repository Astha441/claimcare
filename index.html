✚ claimcare

Patient Locker & Auto Query Response

This folder contains the full-stack product. Start the local server to open the authenticated portal:

  1. Use Node.js 20.16 or newer.
  2. From this folder run npm install, then npm start.
  3. Open http://127.0.0.1:4173.

See README.md for setup and WhatsApp/email provider configuration. The server uses synthetic sample profiles and keeps uploaded files and records encrypted at rest.
